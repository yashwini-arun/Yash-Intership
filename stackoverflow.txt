ERROR: TypeError: 'NoneType' object is not subscriptable
CAUSE: A variable is None and you are trying to index into it using [] or access an attribute.
FIX: Always check if the variable is None before accessing it.
EXAMPLE:
  # Bad
  result = get_data()
  print(result[0])  # crashes if get_data() returns None

  # Good
  result = get_data()
  if result is not None:
      print(result[0])
